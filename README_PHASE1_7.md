# ERI DI-ERY Phase 1.7 — TMI 그림일기 문체

초기 TMI 문장을 딱딱한 관찰 기록체에서 짧은 그림일기체로 변경합니다.

예:
- 기존: `물그릇 가장자리에 앞발을 걸치고 앉아 있는 모습이 관찰됨.`
- 변경: `오늘은 에리가 물그릇 가장자리에 앞발을 걸치고 앉아 있었다. 작은 욕조 앞에 앉아 있는 것 같아서 웃겼다. 참 귀여웠다.`

## 데이터 보존
기존 seed TMI만 같은 id 기준으로 교체합니다.
사용자가 직접 추가한 TMI는 삭제하거나 덮어쓰지 않습니다.

## 적용
ZIP 내용을 `C:\dev\ERI-DI-ERI`에 덮어쓰기.

변경 파일:
- `src/lib/seed.ts`
- `src/lib/storage.ts`
