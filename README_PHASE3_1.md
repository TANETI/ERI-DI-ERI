# ERI DI-ERY Phase 3.1 — 급여량 확장 · 성장 통계 · 홈 날씨

## 1. 급여량 기록 방식 확장

기본 입력은 기존 방식 그대로 유지합니다.

### 기본
- 안 먹음
- 맛만 봄
- 소량
- **보통 ← 기본값**
- 많이
- 거의 다 먹음

급여 기록 창을 열고 아무것도 건드리지 않으면 `보통`으로 저장됩니다.

### mL 대응
나중에 실제 급여량을 계량하기 시작하면 기록 방식에서 선택할 수 있습니다.

- `체감 단계` ← 기본
- `mL`
- `둘 다`

따라서 기존 기록 방식은 전혀 버리지 않고,
필요한 시점부터 mL 데이터를 병행할 수 있습니다.

데이터 모델:
- `amount`: 0~5 체감 단계
- `amountMl`: 선택적 실제 mL 값

기존 기록은 자동으로 그대로 호환됩니다.

## 2. 급여량 추세

`더보기 → 통계`

급여량 그래프에서:

- `체감 단계` ← 기본
- `mL`

를 바꿔 볼 수 있습니다.

두 방식 모두 동일하게:
- 기록 수
- 평균
- 최근 값
- 직전 기록 대비 변화
- 날짜별 그래프

를 계산합니다.

mL 기록이 아직 하나도 없다면 빈 그래프 대신
“mL 기록을 시작하면 여기에 추세가 생긴다”는 안내가 표시됩니다.

기간:
- 최근 30일
- 최근 90일
- 전체

## 3. 체중 성장 통계

같은 통계 화면에 체중 그래프도 추가했습니다.

- 측정 수
- 평균
- 최근 체중
- 직전 대비 변화
- 날짜별 성장선

첫 체중을 아직 측정하지 않았다면 빈 상태로 표시됩니다.

## 4. 에리 이스터에그 속도

기존에는 이동 거리와 상관없이 같은 시간에 도착했습니다.

이제 실제 이동 거리를 계산해:

- 가까운 곳: 약 312ms
- 중간 거리: 약 400~600ms
- 아주 먼 곳: 최대 약 820ms

정도로 이동합니다.

그래서 화면 반대편까지 갈 때도 여전히
“와, 빠르다!” 싶은 속도지만 눈으로 쫓을 시간이 생깁니다.

고개가 이동 벡터를 보는 기능과
좌우로 몸을 뒤집으며 달리는 모션은 그대로 유지합니다.

## 5. 오늘 날씨를 홈 상단으로 이동

지역 날씨 카드를 급여/체중 카드 아래가 아니라
**홈 헤더 바로 아래**로 올렸습니다.

첫 화면에서 바로:
- 오늘 지역
- 최저~최고 기온
- 습도
- 강수
- 냉방/분무 확인 안내

를 볼 수 있습니다.

지역을 아직 설정하지 않았다면 같은 자리에
`더보기 → 설정`에서 지역을 지정하라는 안내가 표시됩니다.

## 보고서

보고서의 급여 섭취 분석도 이제 두 자료를 분리합니다.

- 체감 단계 평균 / 분포
- mL 평균 / 범위

둘 중 하나만 기록되어 있어도 다른 쪽을 억지로 추정하지 않습니다.
