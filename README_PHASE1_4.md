# ERI DI-ERY Phase 1.4 Patch

이번 패치는 달력의 급여 표시를 단순화합니다.

예:
- 급여 예정 회차: 2026-08-31
- 실제 급여: 2026-09-01 02:00
- 달력 표시 위치: 8월 31일 칸
- 표시 문구: `급여 기록 / 9/1 오전 2시`

즉 실제 급여일 칸에 별도의 "실제" 배지를 중복 표시하지 않습니다.

## 적용

1. `src/pages/CalendarPage.tsx` 를 덮어씁니다.
2. `styles_PHASE1_4_APPEND.css` 내용을 현재 `src/styles.css` 맨 아래에 붙여넣습니다.
