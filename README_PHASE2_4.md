# ERI DI-ERY Phase 2.4 — Cleanup & Preset v2

이번 패치는 새 기능을 늘리기보다 기록 화면과 프리셋 구조를 정리하고,
로컬 개발 중 느껴지던 불필요한 버벅임을 줄이는 데 초점을 맞춥니다.

## 1. 급여 기본값

요청 반영:

- 새 급여 기록을 열면 섭취량 기본 선택은 `보통`
- 아무것도 건드리지 않고 저장하면 `보통`으로 기록
- 정말 모르는 경우에는 직접 `미기록`을 선택 가능

즉 평소 입력은 훨씬 빠르게 하고,
과거 기록처럼 양을 모를 때만 `미기록`을 명시적으로 사용합니다.

## 2. 프리셋 v2

### 활동성 — 단일 선택
- 평소와 비슷
- 평소보다 조용함
- 평소보다 활발함

같은 날짜에는 하나만 남습니다.
선택한 항목을 다시 누르면 해제됩니다.

### 위치 — 복수 선택
- 은신처
- 유리벽
- 천장
- 가지
- 잎
- 바닥
- 물그릇 주변

누르면 체크, 다시 누르면 해제됩니다.

### 탈피 — 복수 선택
- 탈피 징후
- 탈피 중
- 탈피 완료
- 잔피부 보임

### 신체 관찰 — 관찰 문장 중심
- 특이사항 없음
- 외상 보임
- 호흡이 평소와 다름
- 균형이 평소와 다름
- 붙는 힘이 평소보다 약함

`특이사항 없음`은 다른 신체 관찰 항목과 동시에 선택되지 않습니다.

## 3. 제거한 애매한 프리셋

새 빠른 체크에서는 아래 항목을 더 이상 사용하지 않습니다.

- 식욕 변화
- 움직임 변화
- 배변 변화
- 탈피 문제
- 외상 관찰
- 호흡 변화

이유:
- 식욕은 급여 섭취량으로 기록
- 배변은 전용 배변 기록으로 기록
- 활동은 활동성 프리셋에서 기록
- 나머지는 방향성이 명확한 관찰 문장으로 교체

기존에 저장된 옛 `health` 기록은 삭제하지 않습니다.
기록 관리 목록에서 계속 확인/수정/삭제할 수 있습니다.

## 4. 체크리스트처럼 동작

프리셋 버튼을 누를 때마다 새 레코드를 계속 추가하던 구조를 정리했습니다.

현재 선택 상태가 버튼에 바로 표시되고:
- 클릭 → 체크
- 다시 클릭 → 해제
- 활동성 → 자동 단일 선택
- 같은 프리셋 중복 저장 방지

로 동작합니다.

## 5. 상세 입력 아코디언

급여 / 체중 / 배변 / TMI 입력창을 처음부터 전부 렌더하지 않습니다.

`상세 기록 추가`에서:
- 🍚 급여
- ⚖️ 체중
- 💩 배변
- 💬 TMI

중 필요한 항목만 열 수 있습니다.

화면 길이가 짧아지고 입력 요소 수도 줄었습니다.

## 6. 가벼운 성능 정리

- `store.initialize()`를 App 렌더마다 호출하지 않고 앱 시작 시 한 번만 실행
- 개발 모드의 React StrictMode 이중 렌더 제거
- 날짜를 빠르게 넘길 때 이전 날씨 fetch를 AbortController로 취소
- 하단 네비게이션의 무거운 backdrop blur 제거
- 프리셋 그룹 변경을 한 번의 상태 업데이트로 처리
