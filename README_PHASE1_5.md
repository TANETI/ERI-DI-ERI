# ERI DI-ERY Phase 1.5 — UI cleanup

## 핵심 변경

### 달력
- 급여 표시를 작은 체크리스트 스타일로 회귀
- 완료: `☑ 🍚 급여`
- 예정: `☐ 🍚 급여 예정`
- 실제 급여 시간이 자정을 넘긴 경우에도 해당 급여 회차의 칸에 작은 보조 텍스트로 표시
- 체중 / 배변 / 환경 / TMI는 작은 한 줄 항목
- 한 날짜의 표시가 4개를 넘으면 `+N개`로 축약
- 검은 테두리/강한 outline 제거
- 오늘 날짜는 작은 세이지 점 + 연한 배경으로만 표시

### 폰트
설정 > 화면에서 선택:
- 기본 시스템
- 맑은 고딕
- Pretendard 우선
- 명조/바탕
- 둥근 고딕

설정은 localStorage에 저장되고 앱 전체에 즉시 적용됩니다.

### 정돈
- 기존 append CSS 누적을 없애고 `src/styles.css`를 완전 교체
- 헤더, 카드, 폼, 달력, 설정 간격과 테두리를 통일
- `더보기` 페이지의 제목을 `설정`으로 정리
