# ERI DI-ERY Phase 3.2.1 — 기상청 API 보류 / 구래동 좌표 고정

기상청 공공데이터 API의 활용 절차가 개인 프로젝트에 번거로워
Phase 3.2의 기상청 전환은 보류합니다.

대신 기존 Open-Meteo 구조는 유지하면서
날씨 위치를 광역 김포시가 아니라 **김포시 구래동**으로 고정합니다.

## 기본 위치

표시:
- 경기도 김포시 구래동

예보 요청 좌표:
- 위도 37.64368
- 경도 126.62370

이 좌표는 구래동 내부의 여러 공개 주소 좌표를 참고해
동네 중심부에 가깝게 잡은 개인 앱용 대표점입니다.

## 장점

- 별도 API 키 없음
- 사업자/활용신청 없음
- 기존 날씨 코드 그대로 활용 가능
- 홈 첫 화면에 바로 표시
- 달력 미래 날짜 예보도 그대로 사용
- 나중에 Cloudflare로 옮기기 쉬움

## 설정 화면

기존의 광역 지역 검색 UI는 제거했습니다.

개인용 앱이므로:
`우리 집 기준 지역: 경기도 김포시 구래동`

으로 고정해서 보여줍니다.

## 적용

이 패치는 Phase 3.1 기준으로 적용하면 됩니다.

ZIP 내용을:
`C:\dev\ERI-DI-ERI`

에 덮어쓰세요.

교체:
- `src/lib/storage.ts`
- `src/pages/MorePage.tsx`
- `src/components/WeatherContextCard.tsx`
- `src/styles.css`

그리고 최신 초기 급여량 보정:
- 소량
- 보통
- 보통

도 포함했습니다.

중요:
이 패치는 Phase 3.2 KMA 패치를 적용하지 않은 상태를 기준으로 합니다.
이미 KMA 패치를 덮어썼다면 이 ZIP을 다시 덮어쓰면 날씨 쪽이 Open-Meteo 방식으로 돌아옵니다.
