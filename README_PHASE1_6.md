# ERI DI-ERY Phase 1.6 — Daily / Monthly calendar

## 달력 탭 기본 동작
- 기본 화면: 일간 보기
- 보조 화면: 월간 보기
- 상단 토글로 언제든 전환

## 일간 보기
- 선택한 날짜를 크게 중앙 표시
- 좌/우 버튼으로 하루씩 이동
- 모바일에서 좌/우 스와이프로 하루씩 이동
- 키보드 좌/우 방향키 지원
- 선택 날짜 기준 ±3일, 총 7일 미니 스트립
- 급여 / 체중 / 배변 / 온도 / 습도 / 관찰 / TMI를 여유 있게 표시
- `+ 이 날짜에 기록 추가`

## 월간 보기
- 기존 월간 그리드 유지
- 셀 안에는 `☑🍚`, `☐🍚`, `⚖`, `💩`, `🌡`, `💬` 정도만 표시
- 날짜를 누르면 자동으로 해당 날짜의 일간 보기로 이동
- 긴 텍스트는 월간 셀에 넣지 않음
