# ERI DI-ERY Phase 3.3 — 통계 화면 정돈

통계 기능 자체는 유지하고, 화면 구조만 조금 더 읽기 쉽게 다듬습니다.

## 변경점

### 기간 선택
기존에는 급여 카드와 체중 카드에 각각 기간 버튼이 있었습니다.

이제 통계 화면 상단에 한 번만:

- 30일
- 90일
- 전체

를 표시하고 두 그래프가 같은 기간을 사용합니다.

### 급여량
체감 단계 / mL 전환은 그대로 유지합니다.

버튼 옆 숫자는 현재 기간의 실제 데이터 개수입니다.

예:
- 체감 단계 3
- mL 0

### 최근 값을 먼저 표시
그래프를 읽기 전에 바로:

- 최근 급여
- 평균
- 직전 기록 대비 변화

를 볼 수 있습니다.

현재 초기 기록이:
- 소량
- 보통
- 보통

이라면 대략:

- 최근: 보통
- 평균: 보통권 · 2.67/5
- 직전 대비: 같음

처럼 표시됩니다.

### 체감 단계 그래프
`보통 = 3` 위치에 점선 기준선을 추가했습니다.

그래프가 위/아래로 흔들릴 때
‘보통’을 기준으로 얼마나 변했는지 더 쉽게 볼 수 있습니다.

### 요약
급여 하단 요약은:
- 기록
- 평균
- 범위

체중 하단 요약은:
- 측정
- 최저
- 최고

로 단순화했습니다.

### 빈 상태
아직 mL나 체중 기록이 없을 때
큰 빈 그래프 대신 짧은 설명 카드가 표시됩니다.
