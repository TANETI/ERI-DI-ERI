# ERI DI-ERY Phase 2.6 — 에리 달리기 모션 수정

의도 수정:

기존 Phase 2.5에서는 이동 방향에 따라 이모지가 한 번 좌/우 반전되도록 했습니다.

이번에는 이동하는 **동안 계속 좌우반전**되도록 변경했습니다.

즉:

`🦎 → (좌우반전) → 🦎 → (좌우반전) → ... → 쀽!`

처럼 약 0.096초 간격으로 빠르게 몸 방향이 번갈아 바뀝니다.

CSS 애니메이션은 `step-end`를 사용하므로
중간에 이모지가 납작하게 찌그러지는 대신 순간적으로 탁탁 뒤집힙니다.

목적지에 도착하면 애니메이션은 즉시 멈추고 평소 모습으로 돌아옵니다.
