# ERI DI-ERY Phase 5.5.3 — Desktop UI v2

컴퓨터 버전을 단순히 "모바일 화면 + 사이드바"가 아니라
실제로 넓은 화면을 활용하는 관리 화면으로 바꿉니다.

## 오늘

Desktop `/desktop`에서:

```text
┌───────────────────────────────────────────────┐
│ ERI DI-ERY / 오늘                             │
├───────────────────────────────────────────────┤
│ 오늘 날씨 · 시간대 다이얼                     │
├───────────────────────┬───────────────────────┤
│                       │ 급여                  │
│     오늘의 에리       ├───────────────────────┤
│       사진            │ 체중                  │
│                       ├───────────────────────┤
│                       │ + 오늘 기록하기       │
├───────────────────────┴───────────────────────┤
│ 최근 급여 기록                                 │
└───────────────────────────────────────────────┘
```

## 달력

일간 화면에서:
- 왼쪽: 그날 기록 요약
- 오른쪽: 날씨 + 기록 관리 버튼
- 월간 셀 높이를 키워 기록 아이콘 가독성 개선

## 기록

- 빠른 체크를 2열로 사용
- 기록 목록을 넓은 화면에서는 2열 카드로 표시
- 급여/체중/배변/TMI 상세 진입을 4버튼 한 줄로 배치

## 앨범

- 대형 화면: 사진 4열
- 작은 노트북: 3열
- hover 피드백과 여백 조정
- 업로드 영역을 가로형으로 활용

## 더보기

- 설정 2열
- 통계 요약 그리드 확대
- 상단 모드 전환을 desktop에서 sticky 처리

## Mobile

`/mobile`의 기존 화면/하단 내비게이션은 건드리지 않습니다.
