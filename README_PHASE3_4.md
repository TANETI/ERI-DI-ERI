# ERI DI-ERY Phase 3.4 — 4시간 단위 날씨

하루 전체 `18.3–27.5℃` 같은 넓은 범위는 작은 보조 정보로 남기고,
실제 날씨 카드는 **4시간 단위 6구간**으로 표시합니다.

## 시간 구간

- 00–04 · 밤
- 04–08 · 새벽
- 08–12 · 오전
- 12–16 · 낮
- 16–20 · 저녁
- 20–24 · 밤

각 카드에는:
- 해당 4시간 기온 범위
- 습도 범위
- 강수량 또는 강수확률

을 표시합니다.

오늘 날짜의 카드에서는 현재 시간이 들어 있는 구간을
`지금`으로 강조합니다.

## 가로형

데스크톱:
6개 구간이 한 줄에 전부 표시됩니다.

모바일:
세로로 쌓지 않고 **가로 스크롤**로 유지합니다.

## 하루 전체 정보

카드 상단에는 작게:
- 하루 전체 최저~최고 기온
- 하루 습도 범위
- 하루 강수
- 데이터 출처

만 남깁니다.

기존 관리 알림은 그대로 아래에 유지됩니다.

## 데이터

Open-Meteo에서 이미 받고 있던 시간별 자료를 그대로 사용하며
추가 API 요청은 없습니다.

기존 3시간 캐시는 4시간 구간 자료가 없기 때문에
패치 적용 후 최초 1회 자동으로 새 데이터를 받습니다.
