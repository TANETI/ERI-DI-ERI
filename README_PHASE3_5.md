# ERI DI-ERY Phase 3.5 — 2시간 날씨 다이얼

날씨 구간을 4시간에서 **2시간 단위 12칸**으로 더 잘게 나눕니다.

## 시간 구간

00–02 / 02–04 / 04–06 / 06–08 / 08–10 / 10–12 /
12–14 / 14–16 / 16–18 / 18–20 / 20–22 / 22–24

각 칸에는:
- 기온 범위
- 습도 범위
- 강수량 또는 강수확률

을 표시합니다.

## 다이얼형 가로 스크롤

12칸을 한 화면에 억지로 넣지 않고 항상 가로 스크롤 가능하게 했습니다.

- 각 칸은 가운데 스냅
- 좌우 끝은 살짝 흐려져 다이얼 느낌
- 중앙 기준 마커
- 모바일/데스크톱 모두 가로 스크롤

## 현재 시간대

오늘 날짜에서는 현재 시간이 속한 2시간 구간이:

- 폭이 조금 더 넓어짐
- 글씨가 조금 커짐
- 배경/테두리 강조
- 페이지를 열면 자동으로 가운데 근처로 이동

예:
14:46이면 `14–16` 카드가 `지금`으로 강조됩니다.

## 하루 전체

기존 요청대로 하루 전체 최저~최고 기온 / 습도 / 강수는
위쪽 작은 보조 정보로 유지합니다.

## 데이터

Open-Meteo의 기존 시간별 데이터를 2시간씩 묶습니다.
추가 API 요청은 없습니다.

기존 4시간 캐시는 자동 무효화되고 최초 1회 새 날씨를 받습니다.
