# ERI DI-ERY Phase 4.1 — ChatGPT 평가 + 실제 관리 결정 이력

보고서 생성 이후의 흐름을 앱 안에서 이어갈 수 있게 합니다.

## 새 탭

`더보기`가:

- 통계
- 평가
- 보고서
- 설정

4개 탭으로 바뀝니다.

## ChatGPT 평가 저장

보고서에서 `ChatGPT 평가용 전체 복사`를 사용한 뒤
ChatGPT가 작성한 평가 답변을 `평가` 탭에 붙여넣어 저장할 수 있습니다.

저장 정보:
- 평가 대상 시작일
- 평가 대상 종료일
- 평가 답변 원문
- 저장 시각

수정 / 삭제도 가능합니다.

중요:
저장된 과거 평가는 관찰 원본과 분리합니다.
새 보고서를 만들 때 과거 평가를 자동으로 넣지 않습니다.
이렇게 해야 이전 해석이 다음 평가에 불필요한 편향으로 들어가는 것을 줄일 수 있습니다.

## 실제 관리 결정

평가와 실제 행동을 별도로 기록합니다.

예:
- 급여 · 적용 · `현재 2일 간격 급여 유지`
- 체중 · 예정 · `첫 측정 성공 후 7일 간격 시작`
- 날씨 · 적용 · `고온 예보일에는 사육장 온도 확인 횟수 늘림`

저장 정보:
- 결정 날짜
- 분류
- 상태
- 결정 한 줄
- 이유 / 메모
- 연결된 ChatGPT 평가 (선택)

상태:
- 예정
- 적용
- 종료

평가 하나에서 여러 관리 결정이 나올 수 있고,
평가와 무관한 개인 판단도 연결 없이 저장할 수 있습니다.

## 왜 따로 저장하나?

`ChatGPT가 이렇게 평가했다`
와
`그래서 실제로 나는 이렇게 관리했다`

는 같은 기록이 아닙니다.

둘을 분리하면 나중에:

1. 당시 기록
2. 당시 평가
3. 실제 관리 변경
4. 이후 에리 상태

를 차례대로 비교하기 쉬워집니다.

## 저장 방식

현재는 다른 구조화 기록처럼 localStorage에 저장합니다.

키:
- `eri-di-ery.evaluations`
- `eri-di-ery.decisions`

D1 서버화 단계에서는 그대로 별도 테이블로 옮길 예정입니다.
