# ERI DI-ERY Phase 2.3 — 기록 수정 / 삭제

이제 기록 탭에서 선택한 날짜의 기존 기록을 직접 관리할 수 있습니다.

## 추가된 기능

`기록` 탭의 날짜 선택 바로 아래에 **이 날짜의 기록** 카드가 생깁니다.

관리 가능한 기록:
- 급여
- 체중
- 배변
- 활동성 / 위치 / 건강 관찰 프리셋
- TMI

각 기록마다:
- `수정`
- `삭제`

버튼이 표시됩니다.

## 수정

수정을 누르면 바로 아래에 해당 종류의 전용 편집 카드가 열립니다.

급여:
- 실제 날짜
- 실제 시간
- 먹이
- 섭취량
- 메모

체중:
- 날짜
- 체중
- 메모

배변:
- 날짜
- 상태
- 메모

관찰:
- 날짜
- 분류
- 내용

TMI:
- 날짜
- 그림일기 내용

수정하면서 날짜를 바꾸면 기록도 새 날짜로 이동합니다.

## 새벽 급여 회차

예를 들어:
- 8/31 급여 회차
- 실제 급여 9/1 02:00

인 경우 8/31 기록 관리 화면에서도 해당 급여가 보입니다.
실제 날짜인 9/1에서도 같은 원본 기록을 관리할 수 있습니다.

## 삭제

삭제는 브라우저 확인창을 한 번 거친 뒤 실행합니다.

체중의 첫 기록을 삭제하거나 날짜를 변경했고,
그 날짜가 현재 체중 측정 일정의 시작일이었다면
남아 있는 가장 오래된 체중 기록을 새 시작점으로 사용합니다.
남은 체중 기록이 없으면 첫 측정일을 다시 비웁니다.

## 작은 UX 수정

새 급여 기록의 섭취량 기본값을 기존의 `보통`에서 `미기록`으로 바꿨습니다.
실수로 섭취량을 기록하지 않았는데 자동으로 `보통`이 저장되는 일을 막기 위한 변경입니다.

달력 일간 화면의 버튼도:
- `+ 이 날짜에 기록 추가`
에서
- `✎ 이 날짜 기록 관리`
로 바뀝니다.
