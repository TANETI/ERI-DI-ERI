# ERI DI-ERY

크레스티드 게코 **에리**의 사육·관찰 기록 웹앱입니다.

## Phase 1.1

Cloudflare 연동 전 로컬 프로토타입입니다.

현재 동작:

- 오늘 화면
- 급여 예정일 계산
- 클릭 가능한 월간 달력
- 날짜별 상세 기록
- 2026-08-30 ~ 2026-09-05 대화 기반 초기 기록
- 급여 실제 기록
- 체중 기록
- 온도/습도 기록
- 배변 기록
- TMI 기록
- 프리셋 빠른 기록
- 급여 주기/시간 로컬 설정
- 브라우저 localStorage 저장

초기 기록 원칙:

- 사용자가 직접 말한 내용만 반영
- 앱 기획 예시에서 임의로 사용한 체중 등의 수치는 제외
- 정확한 급여 시간/섭취량을 모르던 과거 급여는 “미기록” 처리
- 기존 사용자가 입력한 localStorage 데이터를 덮어쓰지 않고 seed id 기준으로 병합

아직 후속 단계:

- D1 데이터베이스 및 스케줄 변경 이력
- R2 사진 저장
- 체중 그래프
- 보고서 / ChatGPT 평가용 Markdown
- PWA / Web Push
- Cloudflare Access

## 실행

```bash
npm install
npm run dev
```
