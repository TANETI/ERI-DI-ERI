# ERI DI-ERY Phase 1.3 Patch

## 변경점

### 1. 달력 테두리 정리
- 버튼 기본 검은 테두리 제거
- 하나의 둥근 그리드 안에서 셀 경계만 얇게 표시
- 오늘 날짜는 검은 outline 대신 sage 색상 inset 표시
- 키보드 포커스는 별도 sage focus ring 사용

### 2. 야행성 급여 회차 인정
기본값:
- 급여 예정일 당일 실제 급여 -> 성공
- 다음 날 06:00까지 실제 급여 -> 전날 급여 회차 성공으로 인정

예:
- 예정 8/31
- 실제 9/1 02:00
- 8/31 급여 회차 = 완료
- 실제 기록 날짜 = 9/1 02:00 그대로 보존

설정 > 급여 설정에서 `다음 날 새벽 인정 마감 (시)`를 0~12 사이로 변경 가능.

이 규칙은 `src/lib/feeding.ts`로 분리되어 향후 보고서 집계에서도 같은 기준을 재사용할 수 있음.
