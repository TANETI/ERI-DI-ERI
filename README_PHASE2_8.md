# ERI DI-ERY Phase 2.8 — 이동 벡터를 보는 에리

이번 수정은 "왼쪽/오른쪽을 본다"가 아니라,
**실제 이동 방향 전체를 고개가 따라가게** 바꿉니다.

예:
- 오른쪽 → 고개도 오른쪽
- 왼쪽 → 고개도 왼쪽
- 대각선 아래 → 고개도 대각선 아래
- 거의 수직 아래 → 고개도 아래
- 대각선 위 → 고개도 대각선 위

구현 방식:
1. 현재 위치와 목적지의 차이로 `atan2()` 이동 각도를 계산
2. 🦎 이모지의 기본 머리 방향(위쪽)을 기준으로 각도 보정
3. 바깥 wrapper가 목적지를 향해 회전
4. 안쪽 이모지만 빠르게 좌우반전

그래서 달리는 동안:
- **머리/진행축은 계속 목적지를 향함**
- **몸은 좌우로 탁탁 흔들림**

즉 좌우반전 때문에 고개가 반대 방향을 보는 문제도 줄였습니다.
